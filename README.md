# ERGOFIT

Plataforma web para seguimiento y gestión del riesgo ergonómico.

## Incluye

- Dashboard con indicadores de población, evaluaciones, riesgo y acciones.
- Registro de evaluaciones ergonómicas.
- Gestión de colaboradores.
- Gestión de intervenciones preventivas y correctivas.
- Biblioteca de pausas activas y ejercicios.
- Gestión básica de usuarios.
- Exportación de evaluaciones a CSV.
- Diseño responsive para computador, tableta y móvil.
- Persistencia de datos en `localStorage` para la versión demostrativa.
- Estructura compatible con GitHub Pages y PWA.

## Acceso demo

Correo: `admin@ergofit.local`  
Contraseña: `ergofit2026`

## Nota de seguridad

Esta versión es una demostración frontend y guarda los datos localmente en el navegador. No debe utilizarse para almacenar información personal o sensible de trabajadores en un entorno institucional. Para producción se recomienda incorporar autenticación segura, base de datos, control de permisos, auditoría y backend.

## Despliegue

El sitio está preparado para publicarse mediante GitHub Pages. Cada actualización de los archivos publicados debe generar un nuevo despliegue mediante GitHub Actions o el mecanismo de Pages configurado en el repositorio.
